Every pick shows the number it carries, with an arrow to today's number when it differs. A number in red moved at least a point since; amber moved less. (parsed) marks a pick whose number was already set before pinning started, so no first-quoted number was preserved: that number is the source's as of that re-parse, not a record of what the picker took; papa game <matchup> shows when each pick was taken. Moneyline is straight-up: "no quoted price" means exactly that, never a stand-in for the current price. Names are grouped by outlet so it is clear where each side's support is coming from.
